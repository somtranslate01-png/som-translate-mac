# Som Translate for Mac (ต้นแบบ 0.1)

**สถานะ: เขียนบน Windows โดยยังไม่เคยคอมไพล์หรือรันบน Mac จริง** อาจมี error ตอนบิลด์ครั้งแรก ต้องมี Mac (หรือ GitHub Actions) ลองและแก้ต่อ

## ทำอะไรได้ตอนนี้
แอปแถบเมนูด้านบน (ไม่มีไอคอนใน Dock): เลือกกรอบ → จับภาพ → อ่านตัวอักษร (Vision) → แปลเป็นไทย (Google เหมือนตัว Windows) → ซับลอยทับล่างจอ
- ⌃⌥1 เลือกกรอบ · ⌃⌥2 เริ่ม/หยุดแปลทุก 1 วินาที (แปลใหม่เมื่อภาพในกรอบเปลี่ยน)
- ซับกว้าง 80% ของจอ ตัวหนังสือ 3.2% ของความสูงจอ (เป็นสัดส่วน ใช้ได้ทุกจอ)
- ซับไม่ถูกอ่านซ้ำ เพราะตอนจับภาพจะตัดหน้าต่างของโปรแกรมเองออก

## ที่ยังไม่มี (เทียบกับตัว Windows)
แถบปุ่มลอย, ธีม, เสียงอ่าน, เลือกภาษา, ปุ่มเลือกฟอนต์, F6/F2, อัปเดตอัตโนมัติ, หน้าตั้งค่า, การจดจำกรอบข้ามการเปิดโปรแกรม

## วิธีบิลด์ (ต้องใช้ Mac, macOS 14+, Xcode หรือ Command Line Tools)
```
cd "Game Translate Mac"
chmod +x build-app.sh
./build-app.sh
```
ได้ `build/SomTranslateMac.zip` (แอปเซ็นแบบ ad-hoc: ครั้งแรกให้คลิกขวา → Open และอนุญาต System Settings → Privacy & Security → Screen Recording)

บิลด์บน GitHub โดยไม่ต้องมี Mac: ดู `github-workflows/mac-build.yml`

## ต้องตรวจเมื่อได้ Mac
1. คอมไพล์ผ่านไหม (ไม่เคยลอง)
2. Vision อ่านภาษาของเกมได้แค่ไหน และ `automaticallyDetectsLanguage` ใช้ได้จริงไหม
3. ซับลอยทับเกมแบบ Borderless/Windowed ได้ไหม (เกมเต็มจอแท้ของ Mac อาจบัง)
4. ปุ่มลัด ⌃⌥ ไม่ชนกับแอปอื่น
5. ถ้าจะแจกจริง: Apple Developer Account เพื่อเซ็น + notarize (ประมาณ 99 ดอลลาร์/ปี)
